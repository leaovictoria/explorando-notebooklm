# 📚 Explorando o NotebookLM: Miniguia de Estudos sobre Planejamento Financeiro Pessoal

Projeto desenvolvido como parte do desafio **"Explorando o NotebookLM"** da DIO (Digital Innovation One), com o objetivo de utilizar Inteligência Artificial como ferramenta de aprendizagem ativa.

Neste projeto, foi utilizado o **NotebookLM** para organizar fontes confiáveis, gerar resumos, comparar informações e consolidar um miniguia de estudos sobre **Planejamento Financeiro Pessoal**.

---

## 🎯 Objetivos

### Objetivo Geral

Compreender os princípios do planejamento financeiro pessoal e desenvolver conhecimentos para organizar receitas, despesas e metas financeiras, favorecendo decisões conscientes sobre o uso do dinheiro.

### Objetivos Específicos

- Entender o conceito de planejamento financeiro.
- Aprender como elaborar um orçamento pessoal.
- Identificar a importância do controle de gastos.
- Compreender a função da reserva de emergência.
- Entender como o planejamento financeiro auxilia na construção do hábito de poupar e investir.

## 🤖 Como utilizei o NotebookLM

O NotebookLM foi utilizado como ferramenta de aprendizagem ativa durante todo o desenvolvimento deste projeto. Após selecionar e adicionar as fontes ao notebook, foram realizadas consultas direcionadas para compreender os principais conceitos sobre planejamento financeiro pessoal.

Durante o processo, a ferramenta foi utilizada para:

- compreender conceitos fundamentais a partir das fontes selecionadas;
- comparar informações apresentadas por diferentes materiais;
- gerar resumos estruturados para cada tópico estudado;
- organizar conceitos em tabelas para facilitar a revisão;
- elaborar um miniguia de estudos;
- criar um glossário com os principais termos relacionados ao tema.

Ao longo das interações, os prompts foram refinados para obter respostas mais claras, objetivas e alinhadas exclusivamente às fontes carregadas no NotebookLM.
